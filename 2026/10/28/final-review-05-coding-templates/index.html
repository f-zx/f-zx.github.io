Web 前端期末复习（五）：四大编程题模板 + 程序填空套路

发表于2026-10-28|更新于2026-10-28|期末复习

这是整个系列最重要的一篇。编程 40 分 + 程序填空 30 分 = 70 分全在这里，而它的特点是：题目是固定的，答案是模板化的。

也就是说，这 70 分本质上是一道”默写题”——你背下来，就能拿。

一、程序填空（30 分）的三类套路

程序填空的考法是：给一段挖了空的代码，让你补全。提纲明确说只会出这三类：

类型 考什么 难度
CSS 补全 选择器、flex 属性、伪类 低，靠认属性名
Flex + 媒体查询 响应式断点 低，靠认 min/max
JSON.parse 的回调 回调签名与返回值 中，要理解逻辑

通用套路：先读注释，再找对称

三看 一看注释——注释里往往直接说了"这里要设主轴对齐""这里处理数组"，等于给答案；
二看对称——代码里前面出现过的属性名，后面大概率要填同类的；
三看括号——CSS 冒号后面、JS 函数括号里缺什么，靠上下文推断。

类型一：CSS 补全

常见空位就这几个，认属性名即可：

类型二：Flex + 媒体查询

判断填 min-width 还是 max-width，就看适配方向：

题干说 填
“屏幕变宽时”、”移动优先” min-width（≥）
“屏幕变窄时”、”小屏适配” max-width（≤）

类型三：JSON.parse 回调

三个空基本就是这三件事：判断数组用 Array.isArray(value)、修改值就 return 新值、不改也要 return value。

最后一个空最容易丢分 如果漏写 return value，整个对象的属性全都会变成 undefined。
记住：回调函数必须每一条路径都有 return。

二、编程第 1 题：Grid 多列布局（8 分）

题目要求

用 Grid 实现：容器内尽可能多列排列，每列最小宽度 250px，剩余空间均分给各列。

标准答案

得分点拆解

得分点 分值 代码
开启网格 2 display: grid;
多列自适应 4 repeat(auto-fill, minmax(250px, 1fr));
单元格基础样式 2 height / background-color
常见扣分 ① 把 auto-fill 写成 auto-fit（题目写了 fill 就照抄，别改）；
② minmax(250px, 1fr) 的括号漏了，或者写成 minmax(250px 1fr)（逗号不能少）；
③ 写成 grid-template-columns: repeat(3, 1fr)——这是固定 3 列，不满足"尽可能多列"。

三、编程第 2 题：过滤小于平均值的元素（8 分）

题目要求

写函数，求数组平均值，返回所有小于平均值的元素；空数组直接返回 []。

标准答案

得分点拆解

得分点 分值 说明
空数组判断 2 if (!arr.length) return [];
求和 2 reduce，初始值 0
求平均 1 sum / arr.length
filter 过滤 3 arr.filter(item => item < avg)
常见扣分 ① 忘了判空 → 空数组时 0/0 得 NaN，返回 `[]` 变成返回 `undefined`；
② reduce 漏了初始值 0；
③ 条件写成 item <= avg（题目是"小于"，不含等于）；
④ 用 forEach 却忘记 return 新数组（`forEach` 没有返回值）。

四、编程第 3 题：倒计时按钮（10 分）

题目要求

页面有一个提交按钮，点击后按钮进入禁用状态，并显示”6 秒后提交”开始倒计时；倒计时结束按钮恢复可点击，文字变回”提交”。

完整代码

如果题目给的是页面一加载就开始倒计时（提纲模板就是这种），去掉点击事件即可：

得分点拆解

得分点 分值 代码
获取按钮 1 document.getElementById('subBtn')
开启循环定时器 2 setInterval(回调, 1000)
数值递减 1 time--
改按钮文字 2 subBtn.innerText = time + "秒后提交"
结束条件 2 if (time <= 0)
清除定时器 1 clearInterval(timer)
恢复按钮 1 subBtn.disabled = false
三个细节 ① 清除定时器必须用 clearInterval（因为开的是 `setInterval`），写成 `clearTimeout` 是错的；
② timer 变量要有名字，才能传给 `clearInterval`——写成匿名的一行就无法清除；
③ 提纲模板里先 time-- 再显示，所以第一屏显示的是"5 秒后提交"而不是 6。如果想从 6 开始，把递减放到 `if` 之后或者调整初始值为 7。按题目给的模板写就行，别自己改结构。

关于 disabled：这个模板假定了按钮初始是禁用的（HTML 里写 <button disabled>）。如果题目没要求初始禁用，那 subBtn.disabled = true 就该放在点击事件里，而不是页面加载时。看清题干。

五、编程第 4 题：fetch + 模板渲染（14 分）

全卷最大单题。流程长但每一步都是固定的。

题目要求

从接口获取用户列表，用 <script type="text/template"> 里的模板渲染到页面容器。

HTML 结构

完整 JS

得分点拆解

得分点 分值 代码
async 异步函数 2 async function fetchUser(url)
发起请求 + await 2 const res = await fetch(url)
解析 JSON（第二个 await） 2 const list = await res.json()
try-catch 容错 2 try { } catch (err) { }
取模板 1 document.getElementById("userTpl").innerHTML
map 替换占位符 3 .map(item => tplStr.replace(...))
join("") 拼接 1 .join("")
渲染到容器 1 .innerHTML = html
三大扣分点（背下来） ① 漏了第二个 await：写 `const list = res.json()`，拿到的是 Promise，后续 `.map` 直接报错；
② 没写 try-catch：网络异常时整个页面崩；
③ 漏了 .join("")：数组直接赋给 innerHTML 会用逗号连接，每张卡片之间多出逗号。

拿分策略：这道题即使你不熟，也一定要写出 async function、try-catch、return 这三样骨架 —— 光是结构就有分。然后再补 fetch 和 innerHTML。空着交是 0 分，写骨架至少能拿 4~6 分。
