Web 前端期末复习（三）：JavaScript 考点（上）

发表于2026-10-27|更新于2026-10-28|期末复习

JavaScript 是这套卷子的绝对重心：13 个考点、独占 40 分编程题。本篇整理前 10 个，基本都在单选、填空、多选里出；后 3 个（数组高阶方法、for…in、fetch）留给下一篇。

这里的每个考点都有一个”陷阱点”，提纲专门用 ⚠️ 标注过，我在下面都单独框出来了。

考点 1：对象解构赋值 + 默认值

★ 必考单选 5 分

两个符号别搞混

符号 含义 作用
: 冒号 属性重命名 把 username 取出来存到 uname 里
= 等号 默认值 属性取不到时用这个值
口诀 「冒号改名，等号兜底。」

默认值什么时候才生效

这是本考点的全部陷阱所在，提纲用了感叹号强调：

默认值生效条件：属性不存在 或者 属性值为 undefined。
对象有这个属性，默认值就不生效！

真题拆解

三个变量产生了三种结果，正好把三种情况演示全了：

变量 情况 结果
uname 用了冒号改名 "wangwu"
age 对象有这个属性 22（默认值 18 被忽略）
gender 对象没有这个属性 "male"（默认值生效）
最高频错点 看到age = 18就以为 age 会变成 18——错。对象里已经有 age: 22，默认值根本不参与。
只有属性不存在、或者显式等于 undefined 时，默认值才顶上。

考点 2：字符串方法 split 与 join

★ 必考单选 6 分

两个方法各管一头

方法 方向 作用
split(分隔符, 切割数量) 字符串 → 数组 按分隔符切开
join(连接符) 数组 → 字符串 用连接符拼回去

split 的第二个参数容易被忽略，它表示返回数组的最大长度——切多了也只要前几个。

真题拆解

如果 split 不写第二个参数，结果会是 ["vue", "react", "angular"]，再 join("|") 就变成 "vue|react|angular"。

题目里的那个 1 是关键，它把数组砍成了只剩一个元素，所以 join 之后也只是一个词。

口诀 split 切开（切成数组），join 缝合（合成字符串）。第二个参数是"最多要几个"。

考点 3：定时器 setTimeout / setInterval 与清除

★ 必考单选 7 分编程第 3 题

两组函数对照记

开启 清除 执行次数 场景
setTimeout(回调, 延时, 参数1, 参数2…) clearTimeout(id) 只执行一次 延迟提示、防抖
setInterval(回调, 延时) clearInterval(id) 循环重复执行 倒计时、轮播图

两个”开启”函数都会返回一个定时器 id，这个 id 就是之后用来清除它的凭据。

单选题爱考这个 调用 clearTimeout(t1) 之后，回调是完全不会执行——不是"只执行一次"。
另一个高频点：清除的是 setTimeout 就用 clearTimeout，清除 setInterval 就用 clearInterval，别把两人的清除函数配错。

编程第 3 题会用到的东西

提纲在这里给了两个提示，是倒计时按钮的必备件：

知识点 用法
按钮的 disabled 属性 btn.disabled = true 禁用 / false 启用
innerText 修改按钮上显示的文字

完整模板见 （五）编程题模板 的第 3 个模板。

考点 4：ES6 模块 import / export

★ 必考单选 8 分

两种导出方式的区别

写法 类型 导入时的规则
export default xxx 默认导出 导入时名字随便起
export { 变量 as 别名 } 命名导出 导入时必须用导出的那个名字（别名）
口诀 default 导出"无名字"，所以导入随便叫；命名导出"有别名"，所以导入必须对上号。

最容易考的一条：导出的是”引用”

提纲用感叹号强调：

导出的是变量引用，模块内部修改变量后，导入处拿到的是更新之后的值！

这和直觉相反 很多人以为 import 拿到的是"导出那一刻的快照"（100）。不是快照，是活引用——模块内部后来改成 200，导入处读到的就是 200。
只有一种情况拿不到更新：你在导入后自己给 count 重新赋值（命名导入的绑定是只读的，会直接报错）。

考点 5：JSON 序列化与反序列化

★ 必考单选 9 分填空 10 空程序填空 3 空

这是题型最多的一个考点（单选 + 填空 + 程序填空三处都出），重点掌握。

两个方法

方法 方向 第二个参数
JSON.stringify(obj) 对象 → JSON 字符串 回调，可过滤/替换要序列化的值
JSON.parse(str) JSON 字符串 → 对象 回调，可修改解析出来的值

序列化规则（必背表）

JSON.stringify 遇到不同类型的值，处理方式完全不同：

值的类型 序列化结果
undefined 直接丢弃，键都不会出现在结果里
函数 直接丢弃
null 保留，输出 null
NaN 转成 null
Infinity / -Infinity 转成 null
有 toJSON() 方法的对象 优先用 toJSON() 的返回值（优先级最高）
填空最爱考 提纲里的填空原题就是这种：一个对象里混着 undefined 和函数，问经过 JSON 转译后还剩几个属性、循环计数是多少。
记住两句话：undefined 和函数"连键带值一起消失"；NaN / Infinity 变成 null（键还在）。所以数剩余属性时，只减去 undefined 和函数，null 和 NaN 要算进去。

JSON.parse 的回调（程序填空考点）

回调的三条铁律：

  1. 函数签名固定是 function (key, value)；
  2. 不需要修改时必须 return value（漏了 return，这个属性就会变成 undefined）；
  3. 判断是不是数组用 Array.isArray(value)。
术语提醒（重要） 提纲里把 JSON.parse 的第二个参数叫作 "replacer 回调"。
严格按标准来说：JSON.parse 的第二个参数叫 reviver，JSON.stringify 的第二个参数才叫 replacer。
考试时按老师提纲的写法答（replacer），别在卷子上纠正老师——你只需要知道标准术语是 reviver，理解不错就行。

考点 6：对象访问属性的两种写法

★ 必考单选 10 分
写法 语法 说明
点语法 obj.key 最常用，key 直接写属性名
方括号语法 obj["key"] 括号里必须写字符串

方括号里不加引号会发生什么

这是本考点的唯一陷阱：

原因：方括号里写的东西会被当成表达式求值。加了引号就是字符串常量；不加引号就是变量名——而这个变量根本不存在，所以是 ReferenceError（不是 undefined，是报错）。

口诀 「方括号里不写引号，等于让 JS 去找一个变量；找不到就直接报错。」
什么时候必须用方括号？属性名是变量的时候：obj[key]——这时不加引号才是对的。

考点 7：箭头函数的 this 指向

★ 必考填空 7 空⚠️ 陷阱

一句话结论（提纲用 ⚠️ 标注的必考点）：

在对象字面量里用箭头函数当方法，this 不指向当前对象，而是指向外层的全局，所以拿不到对象自己的属性，结果是 undefined。

真题代码

为什么是 undefined 而不是 20？

函数类型 this 指向谁
普通函数 function(){} 谁调用指向谁 → 这里是 myObj，能拿到 20
箭头函数 () => {} 定义时所在的外层作用域 → 这里是全局（浏览器里是 window），window.val 不存在 → undefined

改成普通函数就对了

为什么箭头函数拿不到 箭头函数没有自己的 this，它出生时就把 this"锁定"成了外层环境。对象字面量 {} 不会创建作用域，所以箭头函数的外层就是全局作用域，this 指向 window。
换个说法：箭头函数的 this 在"写代码的时候"就定了，而普通函数的 this 在"被调用的时候"才定。
口诀 「箭头函数认爹不认娘，出生在哪就认哪的 this。」

考点 9：字符串 trim / indexOf / split

★ 必考填空 8 空
方法 作用 返回值
trim() 去掉字符串首尾空格 新字符串
indexOf(字符) 查找某个字符第一次出现的位置 找到返回下标，找不到返回 -1
split(分隔符) 按分隔符切成数组 数组

indexOf 找不到返回 -1 这一点必须记牢，因为代码里判断”是否包含”就是靠 !== -1。

真题代码逐行读

跟着走一遍：

步骤 操作 结果
开始 传入参数 " info#company.cn "
① trim() 去首尾空格 "info#company.cn"
② indexOf("#") 有 #，返回下标 4（不是 -1） 条件为 false，不返回
③ split("#") 切成 ["info", "company.cn"] 取 [1] → "company.cn"
口诀 「trim 脱外套（去空格），indexOf 找不到就 -1，split 按刀切完取下标。」

考点 10：高阶函数与箭头函数

★ 必考多选 5 分

什么是高阶函数

参数接收函数，或者返回函数的函数，就叫高阶函数。

只要满足其中任意一条就算，不用两条都满足。

箭头函数的三个限制（多选题考点）

特性 箭头函数
能不能 new 实例化 ❌ 不能
有没有自己的 this ❌ 没有（继承外层）
有没有 arguments ❌ 没有
多选题陷阱 如果选项写"箭头函数可以用 new 创建实例"，直接划掉。箭头函数没有 prototype，也没有自己的 this，所以不能被 new 调用。

自测

4 道自测题（点开看答案）

1. 填空题：const user = { age: 22 }; 执行 const { age = 18 } = user; 后，age 的值是 ______。

答案

22

对象里有 age: 22，默认值 18 不生效。

2. 填空题：JSON.stringify({ a: undefined, b: function(){}, c: null, d: NaN }) 的结果是 ______。

答案

{"c":null,"d":null}

a（undefined）和 b（函数）被丢弃，连键都不保留；c 是 null 保留；d 是 NaN → 转成 null。

3. 单选题：下面代码输出什么？

A. 10　B. undefined　C. 报错　D. null

答案

B

箭头函数作为对象方法，this 指向外层全局（window），window.val 不存在，所以是 undefined。

4. 填空题：function h(fn){ return n => fn(n) - 3; } 执行 h(x => x * 2)(6) 的结果是 ______。

答案

9

先算 fn(6) = 6 * 2 = 12，再 12 - 3 = 9。
