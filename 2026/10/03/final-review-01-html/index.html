Web 前端期末复习（一）：HTML 考点

发表于2026-10-03|更新于2026-10-28|期末复习
|浏览量:

HTML 在这一科里分量最轻——只有 2 个考点，主要出单选和填空。但正因为量小，这几分属于”必须拿到”的送分题，考前半小时就能拿下。

考点 1：HTML 常用标签

★ 必考单选填空基础送分

两个自闭合标签

标签 作用 要点
<hr> 水平分割线 单标签，没有 </hr>
<br> 强制换行 单标签，没有 </br>

这两个最容易考的就是”谁是分割线、谁是换行”，一字之差，别记反。

记法 hr 的 h 就是 horizontal（水平）；br 的 b 就是 break（断开）。
所以 horizonal → 横线（分割线），break → 换行。

块级元素 与 行内元素

这是本节的核心考点，几乎必出多选题。直接背清单：

类型 代表标签 是否独占一行 能否设置宽高
行内（内联）元素 span、a、em、strong ❌ 不独占 ❌ 宽高无效
块级元素 div、h1~h6、p、ul ✅ 独占一行 ✅ 可以设置

记忆时抓住两条本质区别：“独占一行” 和 “宽高有效”。题目问”以下哪个是块级元素”，就按 div / h1~h6 / p / ul 这个清单去找；问”哪个是行内元素”，就找 span / a / em / strong。

口诀 「行内四小：span、a、em、strong 不占行、宽高无效」
「块级四霸：div、h1~h6、p、ul 独占行、宽高随意」

为什么行内元素宽高无效

行内元素的”盒子”是由内容撑出来的，它的尺寸由文字或内容决定，所以 CSS 里写 width / height 不会生效。

想让行内元素能设宽高，用 display: inline-block 把它转成”行内块元素”——既能和别人排在同一行，又能设宽高。

多余但有用的一嘴 `` 和 `` 严格说也属于行内元素，但它们能设宽高——因为它们叫替换元素，尺寸由外部资源决定。
答题时按提纲答"行内元素宽高无效"，这是标准答案；这条例外只用来帮你理解原理，别在卷子上跟老师抬杠。

考点 2：form 表单属性

★ 必考单选 2 分填空 1 分

<form> 是表单容器，它的属性决定了”表单数据怎么送到服务器”。提纲把四个属性列得很清楚：

属性 作用 考试备注
method 提交的 HTTP 请求方法，取值 GET / POST 【单选 2 分】高频
action 提交到的后端接口地址 常考”没写 action 会怎样”
target 提交后在哪个窗口打开 【填空 1 分】
enctype 表单数据编码方式；文件上传必须 multipart/form-data 最容易考填空

method：GET 还是 POST

这是单选题的重灾区。两者最本质的区别是数据放在哪：

对比项 GET POST
数据位置 拼在 URL 后面 放在请求体里
数据是否可见 地址栏看得到 地址栏看不到
长度限制 受 URL 长度限制 基本无限制
是否适合传密码 ❌ 不适合 ✅ 适合
能否收藏/直接访问 ✅ 可以 ❌ 不行
口诀 「GET 挂地址栏，POST 藏请求体」
看到"密码""大段文本""上传文件"，就选 POST；看到"翻页""搜索""分享链接"，就选 GET。

action：提交到哪

action 写的是后端接口的地址。不写 action 时，表单会提交到当前页面本身（这是单选题爱考的细节）。

target：在哪个窗口打开

target 的取值和超链接 <a> 是一模一样的：

取值 含义
_self 当前窗口打开（默认）
_blank 新窗口 / 新标签页打开
_parent 父框架中打开
_top 整个窗口中打开（跳出所有框架）

填空题如果只给一个空，最可能考的就是 _blank 和 _self 这两个。

口诀 self 是自己（当前窗口），blank 是空白（新开一个）。

enctype：文件上传的关键

这是四个属性里最容易白给分的一个，因为答案只有一句话：

表单里有文件上传时，enctype 必须设为 multipart/form-data。

不设的话，文件只会传过去一个文件名，服务器拿不到真正的文件内容。

易错点 `solid`、`dashed` 那一类是 CSS 的 border-style，别和 `enctype` 混在一起记。
另外 `multipart/form-data` 的连字符和斜杠顺序不要写反——考场上手写时"form"在斜杠后面、多部分在后，记成 multipart / form-data。

本节小结

考点 必背内容
常用标签 <hr> 分割线、<br> 换行，都是单标签
行内元素 span a em strong —— 不独占一行、宽高无效
块级元素 div h1~h6 p ul —— 独占一行、可设宽高
form·method GET / POST；GET 数据在 URL，POST 在请求体
form·action 提交到的接口地址；不写就提交到当前页
form·target _self（默认）/ _blank（新窗口）
form·enctype 文件上传必须 multipart/form-data

自测

3 道自测题（点开看答案）

1. 多选题：下列属于块级元素的有（　）

A. span　B. div　C. p　D. a　E. ul

答案

B、C、E

块级清单是 div / h1~h6 / p / ul；span、a 是行内元素。

2. 填空题：表单需要上传文件时，enctype 应设为 ______。

答案

multipart/form-data

3. 单选题：以下关于 GET 和 POST 的说法，正确的是（　）

A. GET 比 POST 安全，适合传密码
B. POST 的数据会显示在地址栏
C. GET 的数据拼在 URL 后面，长度受 URL 限制
D. 两者完全一样，只是名字不同

答案

C

A 说反了（POST 更适合传密码）；B 说反了（POST 数据在请求体，地址栏看不到）；D 错误。

HTML 这 2 个考点建议考前最后看。它们全是纯记忆内容，早看会忘，进考场前 20 分钟翻一遍刚刚好。
