Web 前端期末复习（二）：CSS 考点全解

发表于2026-10-03|更新于2026-10-28|期末复习
|浏览量:

CSS 是这一科题型最全、占分最高的部分：单选、多选、填空、程序填空全都会出。好消息是它的考点高度标准化——属性就那几个、取值就那几档，背下来就能直接换成分数。

本篇覆盖提纲里的 7 个 CSS 考点，其中考点 6、7 是两道纯计算题，等于白送分。

考点 1：position 定位全套

★ 必考单选 3 分多选 3 分

定位的考法只有一个核心：“这个元素相对于谁移动？它原来的位置还占不占？” 把这两个问题的答案记住，四种取值就全通了。

取值 参照物 是否脱离文档流 原来的位置
static 无（普通文档流） ❌ 不脱离 正常占位
relative 自身原来的位置 ❌ 不脱离 仍然保留
absolute 最近的已定位祖先 ✅ 脱离 被后面的元素挤占
fixed 浏览器视口 ✅ 脱离 被挤占

static：默认值

不加 position 就是这个值，元素老老实实待在文档流里，top / left 这些偏移属性完全无效。

relative：相对定位（最容易被扣分的那个）

提纲特意标注了几个细节，全都是考点：

  • ✅ 不脱离文档流，原有位置保留 —— 它挪走之后，原来的坑还在，后面的元素不会补上来；
  • 参照物是自身原来的位置；
  • 不改变元素的 display 属性 —— 行内元素设了 relative 还是行内元素。
高频易错 很多人以为 relative 会"脱离文档流"。不会。它会留下一个等大的空位，看起来像"飘出去了一点点"。
真正脱离文档流的是 absolute 和 fixed。

absolute：绝对定位

  • 参照物：最近的、position 不是 static 的祖先元素（也就是”最近的已定位祖先”）。
  • 脱离文档流：原位置立刻被后面的元素挤占。

如果一路往上找都没有已定位的祖先，它就相对初始包含块（可以粗略理解为页面左上角）定位。

这正是”父相子绝“这个经典搭配的来源：

fixed：固定定位

参照物是浏览器视口，所以页面滚动时它位置不动。典型用途：回到顶部按钮、悬浮客服、固定导航栏。

口诀 「relative 相对自己，位置还留着；absolute 找爹，走了就不回来；fixed 盯着屏幕，怎么滚都不动。」

多选常考：哪些会脱离文档流

会脱离 不会脱离
absolute、fixed、float relative、static

多选就按这个表划勾，别把 relative 混进去。

考点 2：选择器、优先级、伪类、伪元素

★ 必考多选 2 分程序填空 1 空填空 6 空

这一节是 CSS 里考得最碎的部分，但每一条都很短，属于”背了就有”。

伪类与伪元素：看冒号个数

这是最基础的辨析点，一个冒号是伪类，两个冒号是伪元素。

类型 写法 代表 作用
伪类 单冒号 : :focus 获得焦点
:hover 鼠标悬浮
:checked 被选中（radio / checkbox）
:nth-child 第 n 个子元素
伪元素 双冒号 :: ::before 元素内部最前面插入内容
::after 元素内部最后面插入内容
::first-letter 首字母
::placeholder 输入框占位文字的样式
口诀 「冒号一个是个状态（伪类），冒号两个是块内容（伪元素）。」
伪类回答"它在什么状态下"，伪元素回答"凭空多出来的那块东西"。

子代选择器 >

> 和空格的区别必考：> 只管一层，空格管所有层。

选择器优先级

提纲给的顺序是 id > class > 标签选择器。完整的链条（从高到低）是：

优先级 写法 权重 举例
最高 !important — color: red !important;
1 内联样式 style="" 1000 <div style="color:red">
2 id 选择器 100 #box
3 class 选择器（含伪类、属性选择器） 10 .demo、[type="text"]
4 标签选择器（含伪元素） 1 div、p、::before
5 通配符 0 *

怎么看谁赢：分别数一数”id 有几个、class 有几个、标签有几个”，从左往右比，前面一项分出大小就直接结束，不用管后面。比如 .a .b（0 个 id、2 个 class）胜过 div p（0 个 id、0 个 class、2 个标签），因为 class 那一项 2 > 0。

提纲里的原题，非常典型：

答案 orange（橙色）。
三条规则都命中了这个 div：`#box` 是 id（100）、`.demo` 是 class（10）、`div` 是标签（1）。

考点 3：Flex 弹性布局

★ 必考填空 3 空程序填空 2 空多选 4 分

Flex 的所有属性都围绕两条轴，理解了轴，剩下的就是背取值。

六个必背属性

属性 作用 常用取值
display: flex 开启弹性容器 —
flex-direction 设置主轴方向 row（水平，默认）、column（垂直）
flex-wrap 是否换行 nowrap（默认不换行）、wrap（允许换行）
justify-content 主轴对齐 flex-start、center、space-around、space-evenly
align-items 交叉轴对齐 flex-start、center、flex-end
flex-grow 子元素如何分配剩余空间 1 表示自动占满剩余空间

justify-content 的三种 space 值

这三个最容易混，图示记更清楚（假设有 3 个方块）：

取值 效果
flex-start [1][2][3]　　　　　　　　全部靠左
space-between [1]　　　[2]　　　[3]　两端顶格，中间平分
space-around 　[1]　　[2]　　[3]　　每个元素左右间距相等（两端是半个间距）
space-evenly 　　[1]　　[2]　　[3]　　　所有间距（含两端）完全相等
口诀 between 是"之间"——只管元素之间，两端顶格；around 是"周围"——每个元素四周都有间距；evenly 是"均匀"——连两端也算进去平均分。

flex-grow: 1 是什么效果

flex-grow 定义的是”剩余空间怎么分”。设成 1 表示所有设了 1 的子元素等比例吃掉剩余空间，所以三个 flex-grow: 1 的子元素会变成三等分。

易错点 不要死记"justify-content 是水平、align-items 是垂直"。这两个管的是主轴和交叉轴——一旦 `flex-direction: column`，主轴变垂直，两者的作用方向就互换了。

考点 4：Grid 网格布局

★ 必考编程第 1 题约 8 分

这个考点只有一句话要背，但它出现在编程题里，属于”背了就直接拿 8 分”。

题目要求长什么样

请用 Grid 布局实现：容器内尽可能多地排列卡片，每列最小宽度 250px，多余空间平均分给各列。

标准答案

逐段拆开看，每一段都有明确含义：

片段 含义
display: grid 开启网格布局
repeat(...) 重复生成多列
auto-fill 自动填充：一行能塞几列就塞几列
minmax(250px, 1fr) 每列最小 250px，最大为 1fr（均分剩余空间）
必背一行 grid-template-columns: repeat(auto-fill, minmax(最小宽度, 1fr));
把"最小宽度"换成题目给的数字就行，其余一个字符都不要改。

auto-fill 和 auto-fit 的区别（了解即可）：auto-fill 会保留空的列轨道，auto-fit 会把空的列合并掉、让内容拉伸铺满。题目如果写了 auto-fill 就照写，别自作主张换掉。

考点 5：媒体查询 与 移动优先

★ 必考单选 4 分

max-width 和 min-width 的方向

这是本节唯一的失分点，记住”等号在哪边”：

写法 生效条件 通俗理解
max-width: 768px 视口宽度 ≤ 768px “小于等于这个宽度才生效” → 适配小屏
min-width: 768px 视口宽度 ≥ 768px “大于等于这个宽度才生效” → 适配大屏
口诀 max 是"封顶"——屏幕不能比它更大；min 是"起步"——屏幕不能比它更小。

移动优先

提纲明确写了这个概念，简答题/单选都可能出：

移动优先：先写移动端（小屏）样式，再用 min-width 逐步向大屏适配。

为什么这样写？因为手机屏幕小、性能弱，优先保证小屏的基础体验，再用 min-width 一层层”加料”。反过来（先写大屏、用 max-width 往小屏减）叫”优雅降级”，也可以，但提纲要求的是移动优先，答题时写 min-width。

容器居中

这两个属性是固定搭配：max-width 负责”别太宽”，margin: 0 auto 负责”居中”。

★ 必考填空 2 空

纯计算题，公式一行：

例题演练

题目：父盒子宽 1000px，子盒子 width: 600px，用 margin: 0 auto 水平居中。求左右外边距各是多少？

答：左右各 200px，上下为 0。

再练一题

题目：父盒子 1200px，子盒子 900px，左右 margin 相等，求单侧 margin。

两个前提别漏 `margin: 0 auto` 能居中，必须同时满足：
① 元素是块级元素（行内元素无效）；
② 元素有明确宽度（宽度是 auto 时它会撑满父元素，没有居中可言）。
口诀 「父减子，再除二，就是单边外边距。」

考点 7：rem 移动端适配计算

★ 必考填空 4 空

先理解 rem 是什么

rem 是相对于根元素 <html> 的 font-size 的长度单位。

只要改 <html> 的 font-size，所有用 rem 写的尺寸会整体等比缩放——这就是移动端适配的原理。

计算公式

用字母写更直观：

试卷原题

设计稿宽度 375px，设计稿里 1rem 对应 20px；现在设备屏幕宽度是 414px，求根字体大小。

代入公式：

答：22px。

为什么这样算：设计稿里 1rem = 20px，相当于”1rem 占设计稿宽度的 20/375”。到了 414px 的屏幕上，1rem 应该占同样的比例，所以是 414 × (20/375) = 22.08。本质是保持比例不变。

记住这个数：375 → 414

375 和 414 是最常见的两个设计稿/设备宽度，它们之间的缩放系数约为 1.104。看到这两个数字，可以直接 20 × 1.104 ≈ 22 快速验算。

口诀 「新屏宽 × 旧字号 ÷ 设计稿宽」，先乘后除，最后取整。
易错点 别把公式记成"设计稿宽 ÷ 新屏宽"。判断方向的办法：屏幕变宽 → 根字号必须变大。414 比 375 宽，所以结果 22 比 20 大，方向正确。
如果算出来比原来小，肯定是分子分母颠倒了。

自测

4 道自测题（点开看答案）

1. 单选题：元素设置 position: relative 后，下列说法正确的是（　）

A. 元素脱离文档流，原位置被挤占
B. 元素不脱离文档流，原位置保留
C. 元素相对浏览器视口定位
D. 元素会变成块级元素

答案

B

relative 不脱离文档流、原位置保留，参照物是自身原来的位置，且不改变 display。

2. 选择题：伪元素是（　）

A. :hover　B. ::after　C. :focus　D. ::first-letter　E. :nth-child

答案

B、D

双冒号 :: 是伪元素；单冒号 : 是伪类。

3. 填空题：父盒子宽 1000px，子盒子宽 400px，用 margin: 0 auto 居中，则单侧 margin 为 ______。

答案

300px

(1000 − 400) ÷ 2 = 300。

4. 填空题：设计稿宽 750px，1rem 对应 30px，设备屏宽 375px，则根字体大小为 ______。

答案

15px

375 × 30 ÷ 750 = 15。

顺便验证方向：屏幕 375 只有设计稿 750 的一半，所以根字号也应该是 30 的一半 = 15，正确。
