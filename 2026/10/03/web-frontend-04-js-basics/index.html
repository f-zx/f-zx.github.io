script 为什么要放在 body 末尾

demo 里的脚本只是打印日志，所以写在 head 里没问题。但一旦脚本要操作页面元素，就必须放在 body 末尾：

浏览器是从上往下解析 HTML 的。放在 head 的脚本执行时，<body> 里的元素还没被创建出来，自然找不到。放在末尾就能保证元素都已就绪。

另一种做法是给 <script> 加 defer 或 async 属性，或者把代码包进 DOMContentLoaded 事件里。但放进 body 末尾是最简单、最容易理解的方式，初学阶段推荐就用这个。

二、基本语法

demo 12：JS 基本语法

声明变量：var / let / const

关键字 能否重新赋值 说明
var 能 老写法，作用域规则容易出问题，现在基本不用
let 能 现代写法的默认选择
const 不能 声明常量，值不会变就用它

选择顺序很简单：先想 const，确实需要改再换 let，var 就别用了。这样能避免不小心覆盖变量的值。

数据类型

undefined 和 null 容易混：undefined 是”声明了但没赋值”，null 是”我主动把它设成空”。上面 var x; 打印出来是 undefined，而 empty_value 是 null。

循环

for 的三个部分用分号隔开：初始化；条件；每轮结束后执行。while 则需要自己在循环体里改变条件变量，忘了 index++ 就会把浏览器卡死。

break 和 continue

  • i=2 时被 continue 跳过，所以没有 2；

三、函数与作用域

demo 13：JS 函数

三种常见形态

关键区别：return 会把结果交回给调用处，所以能赋值给变量；而 console.log 只是打印，函数本身的返回值是 undefined。

作用域

规则是单向的：

  • 函数内部可以访问外面的全局变量；
  • 函数外部访问不到函数内部的局部变量。

因为局部变量只在函数执行期间存在，函数一结束就销毁了。这就是”作用域链”最基本的表现——由内向外查找，不能反向。

四、事件

demo 14：JS 事件

事件就是”用户做了什么”，绑定事件就是告诉浏览器”发生这件事时执行哪个函数”。

三种常用事件：

事件 触发时机
onclick 鼠标点击
onfocus 元素获得焦点（光标进入）
onblur 元素失去焦点（光标离开）

onfocus / onblur 是表单校验的常用时机——比如用户离开输入框时立刻检查格式对不对。

demo 里把 onclick="..." 直接写在 HTML 标签上，这叫内联事件绑定，优点是直观，缺点是 HTML 和 JS 混在一起不好维护。下一篇 demo 会看到更规范的做法：addEventListener。

五、DOM 查找与修改

demo 15：JS DOM

DOM（文档对象模型）把 HTML 页面变成一棵可以用 JS 操作的对象树。要改页面，第一步永远是先找到那个元素。

三种查找方式

方法 返回 注意
getElementById 单个元素 参数不带 #
getElementsByClassName 集合（类数组） 参数不带 .；要加索引取值
getElementsByTagName 集合（类数组） 要加索引取值

后面两个返回的不是数组而是集合，所以不能直接当元素用。忘记加 [0] 是新手最常见的错误之一。

修改内容：innerHTML 和 innerText

这是两者最重要的差别：

  • innerHTML 会解析 HTML，所以第一个 div 里真的出现了一个可点击的链接；
  • innerText 只当普通文字，第二个 div 里会原样显示 <a href="#">...</a> 这串字符。

innerHTML 用起来方便，但不要用它插入用户输入的内容。用户如果输入 <img src=x onerror="恶意代码">，浏览器会真的执行——这是 XSS 攻击的经典入口。要插入用户内容，请用 innerText 或 textContent。

修改样式

注意 CSS 属性名要转成小驼峰：CSS 里的 font-size 在 JS 里写成 fontSize，background-color 写成 backgroundColor。原因是 font-size 里的横线会被当成减号。

绑定事件的两种方式

addEventListener 的优势是同一个元素可以绑定多个同类型处理函数，它们会依次执行；而 onclick = ... 是赋值操作，再赋一次就把前一个覆盖了。

demo 17：移动端 rem 适配原理

px 的问题

px 是绝对单位。在 375px 宽的手机上，300px 占了 80% 的宽度；换到 414px 的手机上就只占 72%——比例变了，看起来就不一致。

小结

知识点 核心记忆点
导入方式 操作 DOM 的脚本放 body 末尾；用 F12 控制台看输出
基本语法 优先 const，其次 let；continue 跳过本轮，break 结束循环
函数作用域 函数内能访问外面的变量，外面访问不到函数内的
事件 onclick / onfocus / onblur；推荐 addEventListener
DOM 查找 getElementById 返回单个，另外两个返回集合要加索引
innerHTML 会解析 HTML，有 XSS 风险，不要用于用户输入
增删改查 insertRow / insertCell / removeChild；parentNode 往上找
rem 适配 1rem = html 的 font-size，改基准即可整体缩放

四篇总结

整个系列走下来，前端的三个层次已经很清楚了：

层 负责 核心内容
HTML 结构 标签、属性、表单
CSS 样式 选择器、盒子模型、布局
JavaScript 行为 语法、事件、DOM 操作

这三者里，CSS 布局和 DOM 操作是新手最容易卡住的地方——浮动的高度坍塌、定位的参照物、集合忘记加索引，都是必踩的坑。把 demo 挨个改一改、故意改坏再修好，比只看代码印象深得多。
