考点 11：数组 reduce 与 filter

★ 必考编程第 2 题约 8 分

两个方法的分工

方法 作用 返回值
reduce(回调, 初始值) 把数组汇总成一个值 汇总结果（常用于求和）
filter(回调) 把符合条件的元素留下 新数组

reduce 的四个参数

参数 含义
acc 累加器（上一轮的返回值）
cur 当前元素
index 当前下标（可省）
array 原数组（可省）
第二个实参 0 初始值，也就是 acc 的起点

考点 12：for…in 循环 + hasOwnProperty

★ 必考填空 10 空

for…in 遍历对象

for...in 遍历的是对象的可枚举属性名（键），拿到的是”名字”不是”值”：

这里联动考点 6 取值必须写 obj[key]，不能写 obj.key。
因为 key 是一个变量，obj.key 会去找名字就叫 "key" 的属性——找不到，得到 undefined。

为什么要配 hasOwnProperty

for...in 有一个坑：它会连原型链上继承来的属性一起遍历。所以要过滤掉”不是自己的属性”：

方法 作用
obj.hasOwnProperty(key) 判断这个属性是不是对象自身的（而不是从原型继承来的）
口诀 for…in 会"顺藤摸瓜"把爹妈（原型链）的属性也翻出来，hasOwnProperty 就是筛子，只留自己的。

考点 13：fetch 异步请求 + async/await + 模板渲染

★ 必考编程第 4 题14 分 · 全卷最大

这是单题分值最高的考点，也是流程最长的。但拆开看只有两个动作：先拿数据，再渲染到页面。

一、async / await 是什么

  • async function 用来定义异步函数；
  • 在异步函数内部，用 await 等待 Promise 完成，拿到结果。

好处是：原本”回调套回调”的写法，变成了像同步代码一样从上往下读。

二、fetch 的固定三步

步骤 代码 要点
① 请求 const res = await fetch(url) 拿到的是响应对象，不是数据
② 解析 const list = await res.json() 必须再 await 一次，这一步才是数据
③ 容错 try { } catch (err) { } 网络断了、返回 500 都在这里兜
两个 await 都要写 res.json() 本身也返回 Promise，所以前面也要 await。
只写 const list = res.json()，拿到的是 Promise 对象，不是数组——后面 list.map 会直接报错。这是这道题第一大扣分点。

三、模板渲染的四步

HTML 里先放一个”不会被执行”的模板：

type="text/template" 的作用是：浏览器不认识这个类型，所以不会把它当 JS 执行，也不会显示在页面上——它就变成一段”藏起来的字符串”。这样才能安全地当模板用。

然后四步渲染：

步骤 关键 API 作用
① 取数据 await fetchUser(...) 拿到数组
② 取模板 .innerHTML 把模板变成字符串
③ 替换 .map() + .replace() 每条数据生成一段 HTML
④ 拼接 .join("") 数组拼成一个完整字符串
⑤ 渲染 .innerHTML = 一次性塞进页面
第三大扣分点 .join("") 不能漏。少了它，把数组直接赋给 innerHTML 会自动用逗号连接，页面上每张卡片之间会多出一个逗号。
第一个扣分点是漏了 await res.json()；第二个是没写 try-catch；第三个就是这个 join。
口诀 「fetch 拿响应，json 拿数据；模板取 innerHTML，map 换、join 拼、innerHTML 塞。」

这条考点为什么值 14 分

因为它一次考了五样东西：异步（async/await）、请求（fetch）、容错（try-catch）、数组方法（map + join）、DOM 操作（innerHTML）。老师用一个场景把这些缝在一起，所以分最多。

考试时如果 async/await 写不熟，至少把函数骨架写出来：async function 开头、try { } catch { } 结构、return 数据。评分通常按点给分，骨架本身就有分。

2. 填空题：filterLessAvg([1, 2, 3, 4, 10]) 的返回值是 ______。

答案

[1, 2, 3]

sum = 20，avg = 4，小于 4 的是 1、2、3。

3. 单选题：用 for...in 遍历对象时，要过滤掉原型链上的属性，应该用（　）

A. obj.hasOwnProperty(key)
B. Array.isArray(obj)
C. obj.length
D. typeof obj

答案

A

hasOwnProperty 判断属性是否属于对象自身。
